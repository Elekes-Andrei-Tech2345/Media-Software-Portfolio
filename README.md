# Media-Software-Portfolio

# AiVtuber

This is a python/javascript/html program to show a vrm model, while also being able to use vrma animations, it is compatible with koboldcpp as long as the port is matching. To use it just start the server and go to localhost on a browser. This specific project doesn't use js assets through the web, instead the js files need to be in a seperate folder in the project folder, with the folders that contain the model and the vrma files, though the code can be changed to direct it anywhere.

# Soundboard

This is a simple media player, made with pygame, it can be used as a soundboard or simply as a media player. To use it, open it in command prompt (python soundboard.pyw). It can play mp3 files, stop, fastforward and go back ten seconds, you can also change how the ui looks like.

# AnimationChecker

This project is made to check vrma files on a vrm model. It uses python, javascript and html. To use it, start the server through command prompt and go to localhost, choose your specific files and they will play automatically, the animations can also be paused and the camera is moveable.
